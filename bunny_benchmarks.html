About These Demos

Each benchmark renders the Stanford Bunny model with progressively more complex shading. The same GLSL ES 3.00 shaders used here will execute on the TES D/AVE NX programmable GPU via FPGA eval kit, enabling direct visual and performance comparison against the NemaGFX/NemaP CPU-projected approach on Apollo 510 EVB.

All demos are self-contained single-file HTML — no server required. Open directly in any modern browser with WebGL 2.0 support.

Benchmark Demos

B1 — Z-Buffer

Golden Bunny with Normal-Map Lighting

Hardware Z-buffered rendering with a 512×512 normal map for per-pixel lighting. Golden tint via analytical specular (pow-8) and diffuse shading in a teal environment.

Mesh: 700v / 1,146t Textures: 1× normal map
▶ Run Demo CARSW-353
B2 — Reflective

Environment-Mapped Reflective Bunny

Sphere-map environment reflections with per-fragment normal decoding. View vector reflected through transformed normal, then sphere-map sampled for chrome-like appearance.

Mesh: 700v / 1,146t Textures: normal + envmap
▶ Run Demo CARSW-354
B3 — PBR / SSS

Multi-Light PBR with Subsurface Scattering

High-resolution bunny with physically-based rendering: diffuse + specular (pow-24), subsurface scattering, ambient occlusion, distance attenuation, and orbiting point light.

Mesh: 1,582v / 2,729t Textures: normals + additional
▶ Run Demo CARSW-355

CPU Bunny Baseline (Reference)

CARSW-356 — NemaGFX CPU-Projected Bunny

For comparison, the NemaGFX/NemaP path on Apollo 510 EVB uses CPU software transform + sort with nema_fill_triangle_f() for GPU-accelerated flat-shaded triangle fill. No programmable shaders, no Z-buffer, no per-pixel lighting — painter's algorithm only.

Measured: 31.46 ms/frame (31.8 FPS, 36,431 tris/sec) — 700 verts, 1,146 tris, 454×454 RGBA8888.
